# Angular 15 - MockAPI Simple

A lightweight, simplified Angular 15 application connected to MockAPI.io, styled with clean Bootstrap without custom CSS bloat.

## Features
- **Pure Bootstrap Styling**: No custom CSS overhead, minimal templates.
- **Full CRUD with MockAPI.io**:
  - List & filter contacts in real-time
  - Add new contact
  - Edit existing contact
  - Delete contact with confirmation
  - Refresh data directly from API
- **Responsive & Accessible**: Works seamlessly on mobile, tablet, and desktop screens.

## Quick Start

### 1. Install dependencies
```bash
npm install
```

### 2. Run locally
```bash
npm start
```
Navigate to `http://localhost:4200/`.

### 3. Build for production
```bash
npm run build
```
